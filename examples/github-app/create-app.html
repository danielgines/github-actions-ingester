Create the GitHub App for github-actions-ingester

One click creates a private GitHub App inside your organization with read-only access to Actions, Metadata and Contents. The private key is generated by GitHub and handed only to you.

2. Exchange the code for the credentials

After the App is created GitHub redirects to the URL above with ?code=XXXX. Within one hour run:

github-actions-ingester app-convert XXXX --key-file github-app.pem

It prints the App ID and writes the private key (mode 600). Docker works too:

docker run --rm -v "$PWD:/out" -w /out ghcr.io/danielgines/github-actions-ingester \
  github-actions-ingester app-convert XXXX --key-file github-app.pem

3. Install the App and configure the ingester

  1. Open the App page GitHub shows you and click Install App; pick all repositories or only the ones to ingest.
  2. Set GHA_GITHUB_APP_ID and GHA_GITHUB_APP_PRIVATE_KEY (or …_PRIVATE_KEY_FILE) plus GHA_ORGS. The installation is discovered automatically; set GHA_GITHUB_APP_INSTALLATION_ID only when the App is installed in several accounts.
